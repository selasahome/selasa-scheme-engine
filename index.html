Tally Integration

Not connected yet — here's the plan for when you're ready

Since this app now lives on the web (not on your office PC), it has no way to reach Tally directly — a cloud server can't see into your office network. That's a hard limit, not a bug.

The path to real automation later is a small bridge script: a lightweight program that runs on the same office PC as Tally, reads the Sales/Receipt Registers from Tally's local connection, and pushes that data up to this same database over the internet. Nothing else about this app would need to change — the bridge would just fill in Dealers/Invoices/Receipts automatically, the same tables you're already using by hand.

This isn't built yet — flagged here so it's easy to pick up later. Manual entry and CSV import (Dealers/Invoices/Receipts tabs) are fully reliable right now and will keep working exactly the same after a bridge is added.
